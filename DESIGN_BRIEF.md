# Design brief (from David, 2026-10-16)

- **Audience:** BA / PM hiring managers, 60-second read, phones included.
- **Feel:** warm, calm, simple, inviting. Easy to read.
- **Palette:** neutral beige / warm off-white family. Not all black, not all white. No dark/light toggle needed.
- **Layout reference:** https://nahiyan.codes/ (layout and tabbed navigation only, not its look). Single scroll, short labelled sections, lowercase-friendly voice, inline project links, tab-style nav.
- **Voice:** first person, plain. No corny phrases.
- **No list:** corny copy, corny design, anything that reads as AI-generated, grain overlays, gradient blobs, generic card grids, lime-on-black, the old davesal.me look, relocation/remote mentions.
- **Content:** Tetsu is the centerpiece. Amazon analysis optional. AI BA Assistant is left out. Same headshot as the old site (copy from the private repo's assets/ with David's OK, given).
- **Stack:** Astro, static build, GitHub Pages, custom domain davesal.me (CNAME).
- **Resume:** new recruiter version made at the end, after the site is mostly done.
